# KHOHANG-IDOSI

Phân bổ hàng hóa cho cửa hàng IDOSI

## Đăng nhập nhiều tài khoản trong cùng trình duyệt

Mở từng tab Chrome mới và truy cập ứng dụng, sau đó đăng nhập tài khoản Admin, HTKD, cửa hàng hoặc cửa hàng sỉ ở từng tab. Mỗi tab giữ phiên riêng khi tải lại trang; đăng xuất một tab không đăng xuất các tab khác. Sau khi cập nhật lên cơ chế này, các tab đã đăng nhập trước đó cần đăng nhập lại một lần.
